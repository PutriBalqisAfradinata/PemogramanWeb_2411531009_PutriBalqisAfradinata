Laporan Akhir Project — Expense Tracker

Aplikasi Mobile Semester 5 Putri Balqis Afradinata

I. Tujuan Praktikum

  • Mengembangkan aplikasi Expense Tracker menggunakan Flutter dan bahasa pemrograman Dart.
  • Menerapkan form registrasi dan login agar pengguna dapat membuat akun dan masuk ke aplikasi.
  • Menggunakan penyimpanan lokal SQLite untuk menyimpan data pengguna dan transaksi.
  • Menerapkan pengelolaan sesi pengguna menggunakan SharedPreferences.
  • Membuat fitur pencatatan pemasukan dan pengeluaran, ringkasan dashboard, riwayat, detail, dan penghapusan transaksi.
  • Menerapkan navigasi antarhalaman dan mengorganisasi kode ke dalam database, models, screens, services, dan widgets.
  • Membangun aplikasi menjadi APK release untuk diuji dan didistribusikan.

II. Dasar Teori

Flutter merupakan framework untuk membangun antarmuka aplikasi dengan satu basis kode, sedangkan Dart adalah bahasa pemrograman yang digunakan dalam project ini. Struktur antarmuka disusun menggunakan widget dan halaman aplikasi.

SQLite adalah database relasional lokal yang digunakan untuk menyimpan data di perangkat. Pada project ini, database memiliki tabel users untuk data akun dan tabel transactions untuk catatan keuangan. Operasi seperti insert, query, dan delete digunakan untuk mengelola data.

SharedPreferences digunakan untuk menyimpan nilai sederhana, yaitu ID pengguna yang sedang login. Saat aplikasi dibuka, ID tersebut diperiksa kembali dan digunakan untuk memuat data pengguna. Data akun dan transaksi tetap disimpan di SQLite.

Model digunakan untuk merepresentasikan data dalam bentuk objek. AppUser merepresentasikan pengguna, sedangkan TransactionModel merepresentasikan transaksi. Pemisahan model membantu proses konversi data database dan penggunaan data di antarmuka.

Navigasi diatur melalui route pada MaterialApp dan fungsi seperti Navigator.pushNamed, Navigator.pop, serta Navigator.pushNamedAndRemoveUntil. Argumen route dapat digunakan untuk mengirim ID pengguna atau objek transaksi ke halaman tujuan.

Validasi form memastikan input penting telah diisi dengan benar sebelum diproses. Pada form transaksi, nama transaksi wajib diisi dan nominal harus berupa angka bulat lebih dari nol.

3. lib/database/app_database.dart

Pengelolaan SQLite dan operasi data

Membuat koneksi database lokal dan tabel users serta transactions. File ini menjadi lapisan akses data: registrasi akun, validasi login, pencarian pengguna, mengambil transaksi per pengguna, memasukkan transaksi, dan menghapus transaksi. Password diproses menggunakan salt dan hash sebelum disimpan.

Lihat source code lengkap file ini 
import 'dart:convert';
import 'dart:math';

import 'package:crypto/crypto.dart';
import 'package:path/path.dart' as p;
import 'package:sqflite/sqflite.dart';

import '../models/app_user.dart';
import '../models/transaction_model.dart';

class AppDatabase {
  AppDatabase._();
  static final AppDatabase instance = AppDatabase._();
  Database? _database;

  Future<Database> get database async {
    if (_database != null) return _database!;
    final databasesPath = await getDatabasesPath();
    final databasePath = p.join(databasesPath, 'expense_tracker_final.db');
    _database = await openDatabase(
      databasePath,
      version: 1,
      onCreate: (db, version) async {
        await db.execute('''
          CREATE TABLE users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            email TEXT NOT NULL COLLATE NOCASE UNIQUE,
            password_hash TEXT NOT NULL,
            salt TEXT NOT NULL,
            created_at TEXT NOT NULL
          )
        ''');
        await db.execute('''
          CREATE TABLE transactions (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            user_id INTEGER NOT NULL,
            title TEXT NOT NULL,
            amount INTEGER NOT NULL,
            type TEXT NOT NULL,
            category TEXT NOT NULL,
            date TEXT NOT NULL,
            note TEXT NOT NULL DEFAULT '',
            FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE
          )
        ''');
      },
    );
    return _database!;
  }

  String _makeSalt() {
    final random = Random.secure();
    return List<int>.generate(16, (_) => random.nextInt(256))
        .map((value) => value.toRadixString(16).padLeft(2, '0'))
        .join();
  }

  String _hashPassword(String salt, String password) =>
      sha256.convert(utf8.encode('$salt:$password')).toString();

  Future<int> registerUser({required String name, required String email, required String password}) async {
    final db = await database;
    final salt = _makeSalt();
    return db.insert('users', {
      'name': name.trim(),
      'email': email.trim().toLowerCase(),
      'password_hash': _hashPassword(salt, password),
      'salt': salt,
      'created_at': DateTime.now().toIso8601String(),
    });
  }

  Future<AppUser?> loginUser({required String email, required String password}) async {
    final db = await database;
    final rows = await db.query(
      'users',
      where: 'email = ?',
      whereArgs: [email.trim().toLowerCase()],
      limit: 1,
    );
    if (rows.isEmpty) return null;
    final row = rows.first;
    final salt = row['salt'] as String;
    final storedHash = row['password_hash'] as String;
    if (_hashPassword(salt, password) != storedHash) return null;
    return AppUser.fromMap(row);
  }

  Future<AppUser?> getUserById(int userId) async {
    final db = await database;
    final rows = await db.query('users', where: 'id = ?', whereArgs: [userId], limit: 1);
    if (rows.isEmpty) return null;
    return AppUser.fromMap(rows.first);
  }

  Future<int> insertTransaction(TransactionModel transaction) async {
    final db = await database;
    return db.insert('transactions', transaction.toMap()..remove('id'));
  }

  Future<List<TransactionModel>> getTransactions(int userId) async {
    final db = await database;
    final rows = await db.query(
      'transactions',
      where: 'user_id = ?',
      whereArgs: [userId],
      orderBy: 'date DESC, id DESC',
    );
    return rows.map(TransactionModel.fromMap).toList();
  }

  Future<void> deleteTransaction({required int transactionId, required int userId}) async {
    final db = await database;
    await db.delete(
      'transactions',
      where: 'id = ? AND user_id = ?',
      whereArgs: [transactionId, userId],
    );
  }
}

Merepresentasikan data transaksi seperti ID, pemilik transaksi, judul, nominal, jenis, kategori, tanggal, dan catatan. Konversi Map membantu menghubungkan objek Dart dengan baris database SQLite.

Lihat source code lengkap file ini 
class TransactionModel {
  const TransactionModel({
    this.id,
    required this.userId,
    required this.title,
    required this.amount,
    required this.type,
    required this.category,
    required this.date,
    this.note = '',
  });

  final int? id;
  final int userId;
  final String title;
  final int amount;
  final String type; // Pemasukan atau Pengeluaran
  final String category;
  final DateTime date;
  final String note;

  bool get isIncome => type == 'Pemasukan';

  Map<String, Object?> toMap() => {
        'id': id,
        'user_id': userId,
        'title': title,
        'amount': amount,
        'type': type,
        'category': category,
        'date': date.toIso8601String(),
        'note': note,
      };

  factory TransactionModel.fromMap(Map<String, Object?> map) => TransactionModel(
        id: map['id'] as int?,
        userId: map['user_id'] as int,
        title: map['title'] as String,
        amount: map['amount'] as int,
        type: map['type'] as String,
        category: map['category'] as String,
        date: DateTime.parse(map['date'] as String),
        note: (map['note'] as String?) ?? '',
      );
}

6. lib/services/session_service.dart

Penyimpanan sesi login

Menggunakan SharedPreferences untuk menyimpan, membaca, dan menghapus ID pengguna yang sedang login. Data transaksi tidak disimpan di SharedPreferences; penyimpanan utamanya tetap SQLite.

Lihat source code lengkap file ini 
import 'package:shared_preferences/shared_preferences.dart';

class SessionService {
  static const String _userIdKey = 'logged_in_user_id';

  static Future<int?> getUserId() async {
    final preferences = await SharedPreferences.getInstance();
    return preferences.getInt(_userIdKey);
  }

  static Future<void> saveUserId(int userId) async {
    final preferences = await SharedPreferences.getInstance();
    await preferences.setInt(_userIdKey, userId);
  }

  static Future<void> clear() async {
    final preferences = await SharedPreferences.getInstance();
    await preferences.remove(_userIdKey);
  }
}

import 'package:flutter/material.dart';
import '../database/app_database.dart';
import '../services/session_service.dart';
import 'login_screen.dart';
import 'main_screen.dart';

class AuthGate extends StatelessWidget {
  const AuthGate({super.key});

  Future<Widget> _resolveScreen() async {
    final userId = await SessionService.getUserId();
    if (userId == null) return const LoginScreen();
    final user = await AppDatabase.instance.getUserById(userId);
    if (user == null) {
      await SessionService.clear();
      return const LoginScreen();
    }
    return MainScreen(user: user);
  }

  @override
  Widget build(BuildContext context) {
    return FutureBuilder<Widget>(
      future: _resolveScreen(),
      builder: (context, snapshot) {
        if (snapshot.connectionState != ConnectionState.done) {
          return const Scaffold(body: Center(child: CircularProgressIndicator()));
        }
        if (snapshot.hasError) {
          return Scaffold(body: Center(child: Padding(
            padding: const EdgeInsets.all(24),
            child: Text('Aplikasi gagal membuka data lokal. Coba tutup dan buka kembali.\n${snapshot.error}', textAlign: TextAlign.center),
          )));
        }
        return snapshot.data ?? const LoginScreen();
      },
    );
  }
}

      if (_filter == 'Pemasukan') return item.isIncome;
      if (_filter == 'Pengeluaran') return !item.isIncome;
      return true;
    }).toList();

    return Scaffold(
      appBar: AppBar(title: const Text('Riwayat Transaksi')),
      body: _loading
          ? const Center(child: CircularProgressIndicator())
          : RefreshIndicator(
              onRefresh: _loadTransactions,
              child: ListView(
                padding: const EdgeInsets.all(16),
                children: [
                  SegmentedButton<String>(
                    segments: const [
                      ButtonSegment(value: 'Semua', label: Text('Semua')),
                      ButtonSegment(value: 'Pemasukan', label: Text('Masuk')),
                      ButtonSegment(value: 'Pengeluaran', label: Text('Keluar')),
                    ],
                    selected: {_filter},
                    onSelectionChanged: (selection) => setState(() => _filter = selection.first),
                  ),
                  const SizedBox(height: 16),
                  if (visibleItems.isEmpty)
                    Padding(
                      padding: const EdgeInsets.only(top: 64),
                      child: Column(children: [
                        Icon(Icons.history, size: 52, color: Colors.grey.shade400),
                        const SizedBox(height: 12),
                        const Text('Belum ada riwayat transaksi'),
                      ]),
                    )
                  else
                    ...visibleItems.map((item) => TransactionTile(transaction: item, onTap: () => _openDetail(item))),
                ],
              ),
            ),
    );
  }
}

Lihat source code lengkap file ini 
String formatRupiah(int amount) {
  final digits = amount.abs().toString();
  final buffer = StringBuffer();
  for (var i = 0; i < digits.length; i++) {
    buffer.write(digits[i]);
    final remaining = digits.length - i - 1;
    if (remaining > 0 && remaining % 3 == 0) buffer.write('.');
  }
  return 'Rp ${amount < 0 ? '-' : ''}${buffer.toString()}';
}

String formatDate(DateTime date) {
  const months = [
    'Januari', 'Februari', 'Maret', 'April', 'Mei', 'Juni',
    'Juli', 'Agustus', 'September', 'Oktober', 'November', 'Desember'
  ];
  return '${date.day} ${months[date.month - 1]} ${date.year}';
}

C. Alur kerja antarfile

  1. Registrasi: register_screen.dart memvalidasi input dan memanggil app_database.dart untuk menyimpan akun. Data akun direpresentasikan menggunakan app_user.dart.
  2. Login: login_screen.dart mengirim kredensial ke database. Jika valid, session_service.dart menyimpan ID pengguna. auth_gate.dart memeriksa sesi ketika aplikasi dimulai.
  3. Memuat dashboard: dashboard_screen.dart meminta daftar transaksi berdasarkan ID pengguna. Setiap baris data dibentuk menjadi TransactionModel dan dihitung menjadi ringkasan keuangan.
  4. Menambah transaksi: add_transaction_screen.dart memvalidasi input, membentuk objek model transaksi, lalu menyimpannya melalui database. Dashboard atau riwayat dapat memuat ulang data setelah form ditutup.
  5. Melihat dan menghapus transaksi: history_screen.dart menampilkan daftar, transaction_tile.dart mengatur tampilan tiap item, dan transaction_detail_screen.dart menampilkan detail serta memproses penghapusan.
  6. Logout: halaman profil atau navigasi utama memanggil penghapusan sesi pada session_service.dart, kemudian aplikasi kembali ke alur autentikasi.

V. Hasil dan Pembahasan

Project Expense Tracker menggabungkan beberapa fungsi utama dalam satu aplikasi, yaitu autentikasi pengguna, penyimpanan data lokal, pencatatan transaksi, ringkasan keuangan, riwayat, detail transaksi, profil, dan logout. Pemisahan file berdasarkan fungsi membuat kode lebih terstruktur serta memudahkan pengembangan dan pemeliharaan.

Penyimpanan data dilakukan melalui SQLite. Tabel users menyimpan informasi akun beserta hash password dan salt, sedangkan tabel transactions menyimpan transaksi yang terkait dengan pengguna melalui user_id. Fungsi query transaksi menggunakan ID pengguna untuk memisahkan data antarakun. SharedPreferences digunakan untuk menyimpan ID sesi, bukan sebagai tempat penyimpanan utama data transaksi.

Dashboard mengambil transaksi dari database dan menghitung total pemasukan, pengeluaran, serta saldo. Form transaksi melakukan validasi sebelum data disimpan. Riwayat dan detail membaca data yang sama dari database, sedangkan penghapusan menghapus catatan yang dipilih berdasarkan ID transaksi dan ID pengguna. Dengan alur ini, perubahan transaksi dapat tercermin kembali pada daftar dan ringkasan setelah data dimuat ulang.

Navigasi aplikasi menggunakan route yang dikonfigurasi pada MaterialApp. Argumen route digunakan untuk meneruskan ID pengguna ke form transaksi dan objek transaksi ke halaman detail. AuthGate memeriksa sesi saat aplikasi dibuka agar halaman yang ditampilkan sesuai dengan status pengguna.

Pada tahap akhir, tampilan UI disesuaikan dengan warna kuning keemasan. Aplikasi kemudian dibangun menggunakan mode release melalui Flutter CLI. Hasil akhir perlu diverifikasi dengan menjalankan APK pada perangkat Android, termasuk pengujian penyimpanan setelah aplikasi ditutup dan dibuka kembali.
